# UX/UI Knowledge Platform
## Master Product, UX, UI, Content Architecture & Technical Specification

**Project Type:** Bangla-first UX/UI Knowledge & Documentation Platform  
**Primary Language:** Bangla  
**Secondary Language:** English  
**Platforms:** Responsive Web + Mobile Web  
**Theme:** Semi-Dark (Default) + Dark + Light  
**Target:** Beginner → Advanced UX/UI learner, designer, developer, product designer, researcher and anyone interested in Human-Centered Design, Psychology and AI UX.

---

# 1. PROJECT VISION

Build a world-class, Bangla-first UX/UI knowledge and documentation platform where a complete beginner can start from zero and progressively learn advanced UX, UI, Human Psychology, Design Principles, Laws, Research, Accessibility, Design Systems, Product Design, AI UX, Human-AI Interaction and emerging digital interaction paradigms.

The platform must not behave like a random blog.

It must behave like:

> **A structured learning system + documentation library + visual reference system + UX/UI encyclopedia.**

The information architecture must make it extremely easy for users to:

- understand where to start
- know what to learn next
- search for any topic
- browse related topics
- compare concepts
- read comfortably
- understand concepts visually
- access platform-specific UI guidance
- move from beginner concepts to advanced concepts progressively.

---
