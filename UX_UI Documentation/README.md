# UX_UI Documentation

Planning workspace for the **UX/UI Knowledge Platform** — a Bangla-first UX/UI knowledge & documentation platform. This folder holds the source spec and the discovery/planning documents required (spec §56, §58) before any implementation begins.

- [`master-srs.md`](master-srs.md) — the source-of-truth spec Morshed provided. Do not edit; log any deviation in `docs/decisions.md`.
- [`../context.md`](../context.md) — this project's users, constraints, and status, in the format the workspace's other projects use.
- `docs/` — the 18 planning documents (Product Architecture through Risks & Trade-offs), plus `decisions.md`.
