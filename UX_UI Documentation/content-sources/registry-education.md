# 🟡 Education Sources — "How do I explain this simply?"

Use these to calibrate a beginner-friendly explanation's *shape and clarity* — never as the source of a fact. If an Education source states a specific number, statistic, or rule, verify it against an Authority or Research source before repeating it.
