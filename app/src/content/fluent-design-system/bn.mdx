## এটা কী?

**Fluent 2** হলো Microsoft-এর বর্তমান ডিজাইন সিস্টেম, যা Windows, Microsoft 365 (Word, Excel, Teams), এবং Microsoft-এর ওয়েব প্রোডাক্ট জুড়ে ব্যবহৃত হয়। এটা ক্রস-প্ল্যাটফর্ম ডিজাইন টোকেন সরবরাহ করে যা ওয়েব, উইন্ডোজ, এবং মোবাইলে কাজ করে।

## Quick Facts

| | |
|---|---|
| মেইনটেইনার | Microsoft |
| প্রথম প্রকাশ | 2017 |
| মূল প্ল্যাটফর্ম | Windows, Web, Office |
| Open Source | হ্যাঁ (MIT) |
| সেরা ব্যবহার | এন্টারপ্রাইজ, প্রোডাক্টিভিটি টুল |

## মূল বৈশিষ্ট্য

- **Depth ও Light** — উপাদানের মধ্যে গভীরতা বোঝাতে আলো ও ছায়ার সূক্ষ্ম ব্যবহার।
- **Motion** — প্ল্যাটফর্ম জুড়ে সামঞ্জস্যপূর্ণ, উদ্দেশ্যপূর্ণ অ্যানিমেশন।
- **Accessibility-first কম্পোনেন্ট** — Microsoft-এর এন্টারপ্রাইজ ব্যবহারকারী বেস বিবেচনায় শক্তিশালী কীবোর্ড/স্ক্রিন-রিডার সাপোর্ট।

## কখন রেফারেন্স করবে

Windows-নির্দিষ্ট কনভেনশন বা এন্টারপ্রাইজ/প্রোডাক্টিভিটি-ফোকাসড প্রোডাক্টের জন্য উদাহরণ খুঁজতে।
