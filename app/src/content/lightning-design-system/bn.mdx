## এটা কী?

**Lightning Design System** হলো Salesforce-এর ডিজাইন সিস্টেম, বিশেষভাবে বৃহৎ CRM ও এন্টারপ্রাইজ ডেটা ম্যানেজমেন্ট প্রোডাক্টের জন্য বানানো — যেখানে জটিল টেবিল, মাল্টি-স্টেপ ওয়ার্কফ্লো, এবং ভূমিকা-ভিত্তিক (role-based) UI প্রাধান্য পায়।

## Quick Facts

| | |
|---|---|
| মেইনটেইনার | Salesforce |
| প্রথম প্রকাশ | 2015 |
| মূল প্ল্যাটফর্ম | Web (CRM) |
| Open Source | হ্যাঁ (BSD-3) |
| সেরা ব্যবহার | এন্টারপ্রাইজ CRM, ডেটা-ঘন মাল্টি-রোল সিস্টেম |

## মূল বৈশিষ্ট্য

- **Object-Oriented UI প্যাটার্ন** — ডেটা রেকর্ড (কাস্টমার, ডিল, টিকিট) কেন্দ্রিক লেআউট প্যাটার্ন।
- **কাস্টমাইজযোগ্য থিমিং** — প্রতিটা Salesforce কাস্টমারের নিজস্ব ব্র্যান্ডিং প্রয়োগের ব্যবস্থা, কোর সিস্টেম ভেঙে না ফেলে।

## কখন রেফারেন্স করবে

মাল্টি-রোল, ডেটা-ঘন এন্টারপ্রাইজ সিস্টেম ডিজাইনের সময় (Level 15 Advanced UX) — বিশেষভাবে যেখানে একই প্রোডাক্ট বিভিন্ন ভূমিকার (সেলস, সাপোর্ট, ম্যানেজার) জন্য ভিন্ন ভিন্ন ভিউ দেখায়।
