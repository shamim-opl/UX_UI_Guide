## এটা কী?

**TAM, SAM, SOM** একটা বাজারের আকারকে তিনটা ক্রমান্বয়ে ছোট, বাস্তবসম্মত স্তরে ভাগ করে — একটা প্রোডাক্টের সম্ভাব্য বৃদ্ধি বাস্তবসম্মতভাবে বোঝার জন্য।

## তিনটা স্তর

```text
┌─────────────────────────────────────┐
│  TAM (Total Addressable Market)      │
│  পুরো সম্ভাব্য বাজার (তাত্ত্বিক সর্বোচ্চ)   │
│  ┌───────────────────────────────┐   │
│  │  SAM (Serviceable Available)   │   │
│  │  যা তোমার প্রোডাক্ট দিয়ে           │   │
│  │  বাস্তবে সেবা দেওয়া সম্ভব          │   │
│  │  ┌───────────────────────┐    │   │
│  │  │  SOM (Serviceable      │    │   │
│  │  │  Obtainable Market)    │    │   │
│  │  │  বাস্তবসম্মতভাবে যা      │    │   │
│  │  │  প্রথম কয়েক বছরে         │    │   │
│  │  │  ধরা সম্ভব               │    │   │
│  │  └───────────────────────┘    │   │
│  └───────────────────────────────┘   │
└─────────────────────────────────────┘
```

| স্তর | সংজ্ঞা |
|---|---|
| TAM | যদি ১০০% বাজার দখল করা যেত, মোট সম্ভাব্য আয়/ব্যবহারকারী |
| SAM | তোমার নির্দিষ্ট প্রোডাক্ট/ভাষা/অঞ্চলের সীমাবদ্ধতা মেনে বাস্তবসম্মত অংশ |
| SOM | প্রতিযোগিতা, বাজেট, সময় বিবেচনা করে প্রথম কয়েক বছরে বাস্তবে ধরা সম্ভব এমন অংশ |

## কেন গুরুত্বপূর্ণ?

শুধু TAM (সবচেয়ে বড়, আকর্ষণীয় সংখ্যা) দেখিয়ে একটা বাজারকে "বিশাল সুযোগ" মনে করা সহজ, কিন্তু বাস্তবে SOM-ই বলে দেয় প্রথম কয়েক বছরে বাস্তবসম্মতভাবে কী অর্জন করা সম্ভব — এটা রিসোর্স পরিকল্পনা ও বিনিয়োগকারীদের কাছে বাস্তবসম্মত প্রত্যাশা সেট করতে ব্যবহৃত হয়।

## বাস্তব উদাহরণ

একটা বাংলাদেশি এডটেক স্টার্টআপের জন্য: TAM = সারা বিশ্বের অনলাইন শিক্ষা বাজার (কয়েকশ বিলিয়ন ডলার, বাস্তবসম্মত না তাদের জন্য), SAM = বাংলাদেশের স্কুল-কলেজ শিক্ষার্থীদের অনলাইন শিক্ষা বাজার (অনেক ছোট, কিন্তু বাস্তবসম্মত), SOM = প্রথম ২ বছরে যতজন শিক্ষার্থীর কাছে মার্কেটিং বাজেট ও টিমের সামর্থ্য দিয়ে পৌঁছানো সম্ভব (আরও নির্দিষ্ট সংখ্যা)।

## Rules / Best Practices

- SOM নির্ধারণ করার সময় বাস্তব সীমাবদ্ধতা বিবেচনা করো — মার্কেটিং বাজেট, টিমের সাইজ, বিক্রয় ক্ষমতা।
- TAM/SAM/SOM অনুমান করার সময় উৎস (সরকারি ডেটা, ইন্ডাস্ট্রি রিপোর্ট) উল্লেখ করো, শুধু অনুমান না করে।

## সাধারণ ভুল

শুধু TAM দেখিয়ে "এটা একটা বিলিয়ন-ডলার সুযোগ" দাবি করা, SAM/SOM বিশ্লেষণ ছাড়াই। একটা বড় TAM থাকা মানে এই না যে তোমার নির্দিষ্ট প্রোডাক্ট সেই পুরো বাজার ধরতে পারবে — বাস্তবসম্মত পরিকল্পনার জন্য SOM-ই আসল সংখ্যা।
