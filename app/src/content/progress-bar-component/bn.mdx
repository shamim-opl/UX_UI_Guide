## Definition

একটা **Progress Bar** একটা লম্বা, চিকন বার যা একটা প্রক্রিয়ার অগ্রগতি ভিজ্যুয়ালি দেখায় — ফাইল আপলোড, ফর্ম-সম্পূর্ণতা, বা লোডিং।

## Anatomy

```text
[████████████░░░░░░░░]  ৬০%   ← Determinate (নির্দিষ্ট শতাংশ জানা)
[▓▓▓▓░░░░▓▓▓▓░░░░]            ← Indeterminate (কতক্ষণ লাগবে জানা নেই, চলমান অ্যানিমেশন)
```

## Purpose

ইউজারকে জানানো একটা প্রক্রিয়া চলছে এবং (সম্ভব হলে) কতটুকু বাকি — অপেক্ষার সময় "কিছু ঘটছে" এই নিশ্চয়তা দিয়ে উদ্বেগ কমানো।

## When to use / When not to use

**ব্যবহার করো:** যখন প্রক্রিয়ার সময়কাল জানা যায় (ফাইল আপলোড %) বা একটা মাল্টি-স্টেপ ফর্মের অগ্রগতি দেখাতে হবে।
**ব্যবহার করো না:** ২০০ মিলিসেকেন্ডের কম সময়ের কাজের জন্য — এত অল্প সময়ে Progress Bar দেখানো নিজেই একটা flash/distraction তৈরি করে।

## Variants

- **Determinate** — নির্দিষ্ট শতাংশ জানা থাকলে (যেমন ফাইল আপলোড ৪৫%)।
- **Indeterminate** — সময়কাল অজানা হলে, একটা চলমান/পালসেটিং অ্যানিমেশন (যেমন সার্ভার রেসপন্সের অপেক্ষা)।
- **Step Progress** — একটা মাল্টি-স্টেপ ফ্লোর কোন ধাপে আছে তা দেখানো (যেমন "ধাপ ২/৪"), দেখো [Zeigarnik Effect](/reference/laws/zeigarnik-effect)।

## States

| State | কখন হয় |
|---|---|
| 0% | শুরু হয়নি |
| In Progress | চলমান, ০-১০০% এর মাঝে |
| 100% / Complete | সম্পন্ন, সাধারণত একটা সাফল্য সংকেত (চেকমার্ক) সহ |
| Error | প্রক্রিয়া ব্যর্থ হয়েছে, বার লাল হয়ে যায় |

## Accessibility

- `role="progressbar"` সহ `aria-valuenow`, `aria-valuemin`, `aria-valuemax` ব্যবহার করো, যাতে স্ক্রিন রিডার বর্তমান অগ্রগতি ঘোষণা করতে পারে।
- Indeterminate অবস্থায় `aria-valuenow` বাদ দাও (কারণ কোনো নির্দিষ্ট মান নেই), শুধু `aria-busy="true"` ব্যবহার করো।

## Mobile / Tablet / Desktop

মোবাইলে Progress Bar সাধারণত পুরো প্রস্থ জুড়ে (ফুল-উইড্থ), স্ক্রিনের উপরে বা নিচে ফিক্সড থাকতে পারে ফাইল আপলোডের মতো ব্যাকগ্রাউন্ড কাজের জন্য।

## Good Example / Bad Example

**ভালো:** একটা ফাইল আপলোডে নির্দিষ্ট শতাংশ (৪৫%) দেখানো, সাথে "১২ MB / ২৭ MB" টেক্সট — ইউজার জানে ঠিক কতটা বাকি।

**খারাপ:** একটা Determinate Progress Bar যা ৯০% এ গিয়ে দীর্ঘক্ষণ আটকে থাকে (আসল প্রগ্রেস প্রতিফলিত করে না) — ইউজার বিভ্রান্ত হয়, মনে করে সিস্টেম আটকে গেছে।
