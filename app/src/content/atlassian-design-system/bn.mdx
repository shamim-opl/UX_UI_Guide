## এটা কী?

**Atlassian Design System** হলো Jira, Confluence, এবং Trello-র মতো প্রোডাক্টের ডিজাইন ভিত্তি — টিম-কোলাবরেশন, ইস্যু-ট্র্যাকিং, এবং প্রজেক্ট-ম্যানেজমেন্ট UI-তে বিশেষায়িত।

## Quick Facts

| | |
|---|---|
| মেইনটেইনার | Atlassian |
| প্রথম প্রকাশ | 2016 |
| মূল প্ল্যাটফর্ম | Web |
| Open Source | হ্যাঁ |
| সেরা ব্যবহার | টিম-কোলাবরেশন, প্রজেক্ট-ম্যানেজমেন্ট টুল |

## মূল বৈশিষ্ট্য

- **কনটেন্ট ডিজাইন গাইডলাইন** — শুধু ভিজ্যুয়াল কম্পোনেন্ট না, UX কপি ও টোন-অফ-ভয়েসের বিস্তারিত নিয়মও অন্তর্ভুক্ত।
- **সহযোগিতা-কেন্দ্রিক প্যাটার্ন** — কমেন্ট, মেনশন, রিয়েল-টাইম আপডেটের মতো মাল্টি-ইউজার ইন্টারঅ্যাকশন প্যাটার্নের উদাহরণ।

## কখন রেফারেন্স করবে

টিম-কোলাবরেশন বা প্রজেক্ট-ম্যানেজমেন্ট টুল ডিজাইনের সময়, বিশেষ করে যেখানে একাধিক ব্যবহারকারী একই কন্টেন্টে একসাথে কাজ করে।
