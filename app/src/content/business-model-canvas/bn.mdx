## এটা কী?

**Business Model Canvas (BMC)** একটা এক-পাতার ভিজ্যুয়াল টুল, যা ৯টা ব্লকে একটা ব্যবসার সম্পূর্ণ কাঠামো দেখায় — একটা দীর্ঘ ব্যবসায়িক পরিকল্পনা লেখার বদলে, একনজরে পুরো মডেল দেখার ও আলোচনা করার সুযোগ দেয়।

## নয়টা ব্লক

```text
┌─────────────┬─────────────┬─────────────┬─────────────┬─────────────┐
│ Key         │ Key         │ Value       │ Customer    │ Customer    │
│ Partners    │ Activities  │ Proposition │ Relations.  │ Segments    │
│             ├─────────────┤             ├─────────────┤             │
│             │ Key         │             │ Channels    │             │
│             │ Resources   │             │             │             │
├─────────────┴─────────────┴─────────────┴─────────────┴─────────────┤
│  Cost Structure                    │  Revenue Streams                │
└─────────────────────────────────────┴──────────────────────────────┘
```

| ব্লক | প্রশ্ন |
|---|---|
| Customer Segments | কাকে সেবা দিচ্ছি? |
| Value Proposition | কী সমস্যা সমাধান করছি, কেন আমাদের বেছে নেবে? |
| Channels | কীভাবে গ্রাহকের কাছে পৌঁছাচ্ছি? |
| Customer Relationships | গ্রাহকের সাথে সম্পর্ক কেমন? |
| Revenue Streams | কীভাবে টাকা আয় হচ্ছে? |
| Key Resources | কী সম্পদ দরকার? |
| Key Activities | কী কাজ সবচেয়ে গুরুত্বপূর্ণ? |
| Key Partners | কার সাথে সহযোগিতা লাগে? |
| Cost Structure | মূল খরচ কোথায়? |

## কেন গুরুত্বপূর্ণ?

একজন Product Designer/PM হিসেবে পুরো ব্যবসার প্রেক্ষাপট বুঝলে একটা ফিচার সিদ্ধান্ত শুধু UX-এর দৃষ্টিকোণ থেকে না, ব্যবসায়িক টেকসইতার দৃষ্টিকোণ থেকেও যাচাই করা যায় — দেখো [Product Design বনাম UX Design](/learn/13-product-design/what-is-product-design)।

## বাস্তব উদাহরণ

একটা অনলাইন টিউশন প্ল্যাটফর্মের BMC: Customer Segments (শিক্ষার্থী + শিক্ষক দুই পক্ষ, একটা Marketplace মডেল), Value Proposition (শিক্ষার্থীর জন্য সুবিধাজনক সময়ে লাইভ ক্লাস, শিক্ষকের জন্য বাড়তি আয়ের সুযোগ), Revenue Streams (প্রতি ক্লাস থেকে কমিশন)। এই ক্যানভাস দেখে টিম বুঝতে পারে একটা নতুন ফিচার (যেমন গ্রুপ ক্লাস) কোন ব্লককে প্রভাবিত করবে — Revenue Streams বাড়াবে, কিন্তু Customer Relationships-এর ধরন বদলে দেবে।

## Rules / Best Practices

- BMC-কে একবার বানিয়ে ফেলে রাখা ডকুমেন্ট না ভেবে, নিয়মিত (ব্যবসা বদলালে) হালনাগাদ করো।
- একটা নতুন ফিচার প্রস্তাব করার আগে ভাবো এটা BMC-এর কোন ব্লককে শক্তিশালী করছে — যদি কোনোটাকেই না করে, এটা হয়তো অগ্রাধিকার না।

## সাধারণ ভুল

শুধু Value Proposition আর Revenue Streams নিয়ে ভাবা, Cost Structure ও Key Resources উপেক্ষা করা। একটা প্রোডাক্ট ইউজারের কাছে মূল্যবান হলেও যদি তা বানাতে/চালাতে খরচ আয়ের চেয়ে বেশি হয়, ব্যবসাটা টেকসই না।
