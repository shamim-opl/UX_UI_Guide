## এটা কী?

**Carbon** হলো IBM-এর ওপেন-সোর্স ডিজাইন সিস্টেম, বিশেষভাবে ডেটা-ঘন, এন্টারপ্রাইজ-গ্রেড প্রোডাক্টের জন্য ডিজাইন করা — ড্যাশবোর্ড, ডেটা টেবিল, জটিল ফর্ম।

## Quick Facts

| | |
|---|---|
| মেইনটেইনার | IBM |
| প্রথম প্রকাশ | 2018 |
| মূল প্ল্যাটফর্ম | Web (এন্টারপ্রাইজ) |
| Open Source | হ্যাঁ (Apache 2.0) |
| সেরা ব্যবহার | B2B/এন্টারপ্রাইজ সফটওয়্যার, ডেটা-ঘন UI |

## মূল বৈশিষ্ট্য

- **২x গ্রিড সিস্টেম** — কঠোর, predictable লেআউট গ্রিড।
- **ডেটা ভিজ্যুয়ালাইজেশন কম্পোনেন্ট** — চার্ট, গ্রাফের সম্পূর্ণ স্পেসিফিকেশন, যা বেশিরভাগ ডিজাইন সিস্টেমে অনুপস্থিত।
- **শক্তিশালী ডকুমেন্টেশন** — প্রতিটা কম্পোনেন্টের ব্যবহারের নিয়ম, অ্যাক্সেসিবিলিটি নোট, এবং কোড উদাহরণ একসাথে।

## কখন রেফারেন্স করবে

[Advanced UX](/learn/15-advanced-ux) (এন্টারপ্রাইজ, ড্যাশবোর্ড, মাল্টি-রোল সিস্টেম) ডিজাইন করার সময় — Carbon-এর ডেটা-ঘন কম্পোনেন্ট প্যাটার্ন অন্যান্য কনজিউমার-ফোকাসড সিস্টেমের (Material, HIG) চেয়ে বেশি প্রাসঙ্গিক।
