## Definition

**Tabs** সম্পর্কিত কিন্তু আলাদা কনটেন্টের সেটের মধ্যে একই জায়গায় সুইচ করার সুযোগ দেয় — একবারে একটা ট্যাবের কনটেন্ট দৃশ্যমান থাকে, বাকিগুলো লুকানো থাকে যতক্ষণ না নির্বাচন করা হয়।

## Anatomy

```text
[ ট্যাব ১ ] [ ট্যাব ২ ]  ট্যাব ৩
━━━━━━━━━
নির্বাচিত ট্যাবের কনটেন্ট এখানে দেখানো হয়
```

একটা ট্যাব-লেবেলের সারি (একটা সক্রিয় নির্দেশক সহ) + নিচে সক্রিয় ট্যাবের কনটেন্ট প্যানেল।

## Purpose

সম্পর্কিত কনটেন্ট (যেমন একটা প্রোডাক্ট পেজে "বিবরণ", "রিভিউ", "স্পেসিফিকেশন") একই পেজে সংগঠিত রাখা, আলাদা আলাদা পেজে ভাগ না করে — ইউজার একই প্রসঙ্গ হারায় না, দ্রুত সুইচ করতে পারে।

## When to use / When not to use

**ব্যবহার করো:** ২-৭টা সম্পর্কিত, সমান-গুরুত্বের কনটেন্ট বিভাগ একই প্রসঙ্গে দেখাতে হলে।
**ব্যবহার করো না:** একটা ধারাবাহিক, ধাপে-ধাপে প্রক্রিয়ার জন্য (তার জন্য একটা Wizard/Stepper ভালো) — Tabs বোঝায় প্রতিটা বিভাগ স্বাধীন, কোনো নির্দিষ্ট ক্রম নেই।

## Variants

- **Horizontal Tabs** — সবচেয়ে প্রচলিত, উপরে সারিবদ্ধ।
- **Scrollable Tabs** — অনেক ট্যাব থাকলে (মোবাইলে সাধারণ), অনুভূমিকভাবে স্ক্রল করা যায়।
- **Vertical Tabs** — সাইডবারের মতো, সাধারণত সেটিংস পেজে ব্যবহৃত।

## States

| State | কখন হয় | ভিজ্যুয়াল ইঙ্গিত |
|---|---|---|
| Active (নির্বাচিত) | এই ট্যাবের কনটেন্ট এখন দৃশ্যমান | রঙিন আন্ডারলাইন/ব্যাকগ্রাউন্ড, bold টেক্সট |
| Inactive | অন্য ট্যাব নির্বাচিত | মিউটেড রঙ |
| Hover | মাউস উপরে (ডেস্কটপ) | হালকা ব্যাকগ্রাউন্ড পরিবর্তন |
| Focus | কীবোর্ড দিয়ে পৌঁছানো হয়েছে | স্পষ্ট আউটলাইন রিং |
| Disabled | এই ট্যাব এই মুহূর্তে উপলব্ধ না | হালকা ধূসর, ক্লিকযোগ্য না |

## Accessibility

- `role="tablist"`, `role="tab"`, আর `role="tabpanel"` ব্যবহার করো, যাতে স্ক্রিন রিডার বুঝতে পারে এটা একটা ট্যাব ইন্টারফেস।
- Arrow key দিয়ে ট্যাবের মধ্যে নেভিগেট করা যাওয়া উচিত, শুধু Tab key দিয়ে না — এটা WAI-ARIA-এর প্রত্যাশিত keyboard pattern।
- সক্রিয় ট্যাব ভিজ্যুয়ালি স্পষ্টভাবে আলাদা হতে হবে (রং, আন্ডারলাইন), শুধু সূক্ষ্ম পার্থক্য না।

## Mobile / Tablet / Desktop

মোবাইলে ৩টার বেশি ট্যাব থাকলে scrollable বা swipeable করা ভালো, কারণ সব ট্যাব একসাথে ছোট স্ক্রিনে না আঁটতে পারে। ডেস্কটপে সাধারণত সবগুলো ট্যাব একসাথে দৃশ্যমান রাখা যায়।

## Good Example / Bad Example

**ভালো:** একটা প্রোডাক্ট পেজে "বিবরণ", "স্পেসিফিকেশন", "রিভিউ (১২৪)" ট্যাব, প্রতিটার লেবেল স্পষ্ট এবং সংখ্যাসহ (রিভিউর ক্ষেত্রে) — ইউজার জানে কোথায় কী পাবে।

**খারাপ:** ৯-১০টা ট্যাব একসাথে গুঁজে দেওয়া, যার ফলে প্রতিটা লেবেল সংক্ষিপ্ত করতে হয় এবং ইউজার বুঝতে পারে না কোন ট্যাবে কী আছে — এত বেশি অপশন থাকলে বরং একটা Sidebar Navigation ভালো বিকল্প।
